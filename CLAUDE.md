# CLAUDE.md

## Project Overview

This repository contains assignments completed as part of the **FlyRank Front-end AI Engineering Internship**.

## Primary Focus

Build modern, responsive, and accessible frontend applications while using AI as a development assistant rather than a replacement for problem-solving.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- Git
- GitHub

## Coding Standards

- Write clean, readable, and maintainable code.
- Use semantic HTML whenever possible.
- Prefer modern CSS techniques (Flexbox, Grid).
- Write modular and reusable JavaScript.
- Use meaningful variable and function names.
- Keep components and files well organized.

## AI Guidelines

- Explain the reasoning before generating code.
- Prefer beginner-friendly explanations.
- Follow frontend best practices.
- Suggest improvements for readability, accessibility, and performance.
- Avoid unnecessary libraries unless requested.

## Git Conventions

Follow the Conventional Commits specification.

Examples:

- feat:
- fix:
- docs:
- style:
- refactor:
- test:
- chore:

## Project Rules Learned

1. Always ask the AI to explain its implementation plan before generating code.
2. Specify the exact files that should be created or modified to avoid unnecessary changes.
3. Require accessibility for all forms, including labels and keyboard navigation.
4. Ask the AI to verify its implementation against the requirements before considering the task complete.
5. Review all AI-generated code manually before committing.
